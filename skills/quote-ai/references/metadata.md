# QuoteAI Metadata Vocabulary

Metadata is deliberately small and composable. Agents should reuse these
values instead of inventing a new label for every prompt.

## Scenarios

- `speech-opening`
- `speech-closing`
- `team-meeting`
- `presentation`
- `leadership`
- `social-post`
- `journal`
- `reflection`
- `morning-routine`
- `night-reflection`
- `relationship`
- `card-message`
- `icebreaker`

Initial curated/rule-assisted collections:

- `stoic-wisdom`
- `leadership`
- `entrepreneurship`
- `resilience-courage`
- `public-speaking`

The vocabulary will evolve slowly. Compatibility is preferred over adding
